# Linear Data Structures

These are the first structures you should implement by hand.

## Recommended Order

1. arrays
2. linked lists
3. stacks
4. queues

## What To Focus On

- contiguous vs non-contiguous memory
- insertion and deletion tradeoffs
- index access vs pointer traversal
- how these structures support common patterns

## Strong Connections

- arrays support sliding window, prefix sum, and two pointers
- linked lists support fast and slow pointers and in-place reversal
- stacks support monotonic patterns
- queues support BFS and streaming problems
