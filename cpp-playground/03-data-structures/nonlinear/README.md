# Nonlinear Data Structures

This section is where DSA starts to feel more structural and less sequential.

## Recommended Order

1. trees
2. heaps
3. hashing
4. graphs

## What To Focus On

- traversal strategy
- structure invariants
- recursion and iterative alternatives
- tradeoffs between lookup, update, and traversal

## Strong Connections

- trees connect to DFS, BFS, and recursion
- heaps connect to top K and scheduling
- hashing connects to constant-time lookup patterns
- graphs connect to traversal, connectivity, and shortest path
