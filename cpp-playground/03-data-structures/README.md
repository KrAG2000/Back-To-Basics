# Data Structures

This section is organized by implementation depth.

## Layout

- `linear/`
  Arrays, linked lists, stacks, and queues.
- `nonlinear/`
  Trees, heaps, hashing, and graphs.
- `advanced/`
  Segment trees, balanced trees, tries, probabilistic structures, and more specialized tools.

## How To Study This Section

1. understand the memory model
2. implement core operations
3. learn the time complexities
4. connect the structure to at least one problem pattern
5. build one small project that uses it
