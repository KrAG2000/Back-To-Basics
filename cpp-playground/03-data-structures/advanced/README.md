# Advanced Data Structures

This section is intentionally later in the learning path.

## Use It After

- arrays and linked lists feel easy
- trees and graphs are no longer scary
- you can solve medium problems with common patterns

## Layout

- `intermediate-structures/`
  Segment trees, balanced trees, tries, spatial structures, and similar tools.
- `composite-structures/`
  Structures built by combining multiple ideas, like caches and specialized queues.
- `specialized-structures/`
  Niche or focused structures you want to study separately.

## Rule

Do not let this section distract you from repetition in `02-patterns/` and `06-problem-solving/`.
