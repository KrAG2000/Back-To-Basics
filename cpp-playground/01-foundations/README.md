# Foundations

This section exists to remove the reasons DSA feels hard before DSA itself becomes hard.

## Learn These First

1. time and space complexity
2. pointers, references, and value vs reference semantics
3. stack memory vs heap memory
4. recursion tracing
5. STL containers, iterators, and common operations
6. debugging with print tracing and invariants

## Outcome You Want

By the time you leave this section, you should be able to:

- explain why an approach is `O(n)` or `O(log n)`
- read pointer-heavy code without panicking
- trace recursive calls on paper
- choose between `vector`, `stack`, `queue`, `unordered_map`, and `set`
- debug off-by-one and boundary issues calmly

## Rule Of Thumb

If a data structure implementation feels magical or a problem solution feels slippery, return here first.
