# Problem Solving

This is where understanding becomes speed.

## Use This Section For

- pattern drills
- solved problems
- revision notes
- reusable templates
- mock rounds

## Recommended Cycle

1. solve a few focused drills in `pattern-drills/`
2. store cleaned-up solutions in `solved-problems/`
3. write one page of insight in `revision-notes/`
4. extract reusable snippets into `templates/`
5. test yourself under pressure in `mock-rounds/`

## Important Rule

Do not only collect answers. Capture what you missed, why you missed it, and what signal should have told you the pattern earlier.
