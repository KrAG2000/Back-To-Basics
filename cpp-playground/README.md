# CPP Playground

This repo is organized to help you learn DSA the way strong problem solvers actually improve:

1. build foundations
2. master common patterns
3. understand data structures deeply
4. connect them to algorithms
5. apply them in projects
6. reinforce everything through problem solving

## Best Learning Order

1. `00-guides/`
   Repo conventions and study rules.
2. `01-foundations/`
   Complexity, memory, recursion, STL, and debugging basics.
3. `02-patterns/`
   The highest-value interview and contest patterns.
4. `03-data-structures/`
   Implement and understand the structures patterns rely on.
5. `04-algorithms/`
   Algorithm families and deeper techniques.
6. `05-projects/`
   Build things that force the concepts to stick.
7. `06-problem-solving/`
   Drills, solved problems, templates, and mock rounds.
8. `90-beyond-dsa/`
   Systems, concurrency, and large-scale ideas for later.

## What Makes This Structure Different

- `02-patterns` is the center of the repo because patterns are what make question-solving faster.
- `03-data-structures` exists so you understand the mechanics behind those patterns.
- `05-projects` turns abstract DSA into something memorable and practical.
- `06-problem-solving` is where you convert understanding into speed.

## Recommended Weekly Loop

1. Pick one pattern from `02-patterns`.
2. Review the required structure in `03-data-structures`.
3. Study the related algorithm family in `04-algorithms`.
4. Solve 5 to 10 questions in `06-problem-solving`.
5. Build or extend one project in `05-projects`.
6. Write one short revision note before moving on.

## If You Want The Fastest Payoff

Start in this order:

1. array and string patterns
2. linked list patterns
3. stack and queue patterns
4. tree patterns
5. heap and greedy patterns
6. graph patterns
7. dynamic programming patterns

That order covers a huge portion of common interview questions and coding rounds.
