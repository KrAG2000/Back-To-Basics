# Array And String Patterns

Start here. This folder gives the fastest return for interview-style practice.

## Master These Patterns

- linear scan
- prefix sum
- suffix preprocessing
- two pointers
- sliding window
- frequency counting
- hashing for lookup

## Recognition Signals

- contiguous subarray or substring
- longest or shortest valid window
- pair sum or triplet style target
- repeated characters or repeated values
- range sum queries

## Common Mistakes

- moving both pointers incorrectly
- forgetting when a window should shrink
- using nested loops when a map would collapse the work
- mixing index logic with value logic
