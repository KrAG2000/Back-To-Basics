# Tree Patterns

This folder is where recursion starts paying off.

## Master These Patterns

- DFS traversal
- BFS traversal
- subtree recursion
- path-based recursion
- binary search tree reasoning
- lowest common ancestor

## Recognition Signals

- root to leaf paths
- height, depth, diameter, or balance
- parent-child dependency
- serialize or deserialize style structure problems

## Common Mistakes

- confusing preorder, inorder, and postorder roles
- not deciding what the recursive function returns
- mixing local answers with global answers
