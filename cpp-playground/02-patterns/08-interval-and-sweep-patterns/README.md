# Interval And Sweep Patterns

This folder covers one of the most reusable scheduling families.

## Master These Patterns

- interval sorting
- merge intervals
- sweep line
- line events
- overlap counting

## Recognition Signals

- ranges with start and end
- meetings, bookings, segments, or coverage
- maximum overlap or merged output

## Common Mistakes

- sorting by the wrong field
- mishandling touching intervals
- forgetting event tie-breaking rules in sweep-line problems
