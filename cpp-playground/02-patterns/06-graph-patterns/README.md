# Graph Patterns

This folder is about turning relationships into traversals.

## Master These Patterns

- graph as adjacency list
- BFS shortest path in unweighted graphs
- DFS for components and cycle detection
- topological sort
- union find
- Dijkstra basics

## Recognition Signals

- dependencies
- islands, clusters, or connected components
- shortest path wording
- prerequisite or ordering constraints

## Common Mistakes

- not clarifying directed vs undirected
- not clarifying weighted vs unweighted
- revisiting nodes due to poor visited-state handling
