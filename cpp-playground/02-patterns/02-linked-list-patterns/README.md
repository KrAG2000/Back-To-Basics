# Linked List Patterns

This folder is about pointer discipline.

## Master These Patterns

- fast and slow pointers
- dummy node usage
- in-place reversal
- merge two sorted lists
- cycle detection

## Recognition Signals

- middle of the list
- cycle or loop detection
- reverse part of a list
- delete a node without special-casing head too much

## Common Mistakes

- losing the next pointer during rewiring
- forgetting dummy nodes for edge cases
- returning the wrong head after reversal
