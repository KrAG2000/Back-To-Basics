# Patterns

This is the highest-leverage section in the repo.

Patterns matter because most DSA problems are not truly new. They are familiar structures wearing different stories.

## How To Use A Pattern Folder

1. learn the recognition signals
2. understand the invariant
3. solve 3 easy problems
4. solve 3 medium problems
5. write one pattern note in `06-problem-solving/revision-notes`

## Core Idea

When you get faster at recognizing patterns, you stop starting every question from zero.
