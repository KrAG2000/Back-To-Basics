# Stack And Queue Patterns

This folder teaches you how to process order and constraints cleanly.

## Master These Patterns

- monotonic stack
- balanced parentheses
- next greater or smaller element
- BFS with queue
- level-order processing
- deque for window maximum

## Recognition Signals

- nearest greater or smaller element
- undo or backtrack history
- level-wise traversal
- first in first out processing
- window max or min queries

## Common Mistakes

- storing values when indices are needed
- forgetting why monotonic order is being maintained
- mixing DFS thinking into BFS problems
