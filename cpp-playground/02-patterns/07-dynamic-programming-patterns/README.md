# Dynamic Programming Patterns

This folder should come after recursion is comfortable.

## Master These Patterns

- 1D DP
- 2D DP
- decision DP
- knapsack-style DP
- subsequence DP
- interval DP

## Recognition Signals

- optimize count, minimum, maximum, or number of ways
- repeated overlapping states
- brute force recursion that repeats work
- a state can be described by a few variables

## Common Mistakes

- choosing a vague state definition
- not writing the transition clearly
- jumping to tabulation before understanding recursion
