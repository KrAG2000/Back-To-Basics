# Heap And Greedy Patterns

This folder helps with selection, scheduling, and local-choice problems.

## Master These Patterns

- top K elements
- running median
- priority scheduling
- interval selection
- greedy sorting with proof intuition

## Recognition Signals

- repeatedly take best available item
- maintain smallest or largest K values
- processing streams
- deadlines, tasks, and meeting rooms

## Common Mistakes

- using sorting when a heap is better for dynamic updates
- applying greedy without knowing why local choice is safe
- choosing the wrong heap orientation
