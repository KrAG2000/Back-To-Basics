# Rate Limiter

## Why Build It

This project makes queues, timestamps, and eviction rules feel concrete.

## Concepts

- queue or deque
- sliding window
- token bucket or leaky bucket thinking
- timestamp cleanup

## Milestones

1. implement fixed window logic
2. implement sliding window logic
3. compare memory and accuracy tradeoffs
4. support multiple users or keys
5. add unit tests around bursty traffic
