# In-Memory Key Value Store

## Why Build It

This project is a great bridge between data structures and system design.

## Concepts

- hash map
- optional TTL expiration
- basic command parsing
- snapshot or persistence as a stretch goal

## Milestones

1. implement `set`
2. implement `get`
3. implement `delete`
4. add TTL support
5. add eviction or persistence as an advanced extension
