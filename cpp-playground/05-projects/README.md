# Projects

This section is where DSA becomes tangible.

Projects are grouped by how close they are to raw data-structure implementation versus real system behavior.

## Layout

1. `01-implementation-level/`
   Small builds focused on one data structure or one strong idea.
2. `02-applied-mini-systems/`
   Realistic but manageable systems that combine several structures.
3. `03-large-scale-systems/`
   Bigger design-heavy builds that simulate production-style thinking.

## How To Use Projects

1. build one implementation-level project after each major pattern group
2. build one applied mini system every few weeks
3. use large-scale projects when you want architecture practice

## Rule

Do not wait until you feel fully ready. Projects are part of how readiness is built.
