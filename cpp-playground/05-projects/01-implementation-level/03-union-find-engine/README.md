# Union Find Engine

## Why Build It

This project makes disjoint set logic intuitive through repeated merging and querying.

## Concepts

- disjoint set union
- path compression
- union by rank or size
- connectivity queries

## Milestones

1. support `find`
2. support `union`
3. track connected components
4. compare naive vs optimized versions
5. demo with network connectivity or island merging
