# LRU Cache

## Why Build It

This is one of the best small projects for combining a hash map with a doubly linked list.

## Concepts

- hash map
- doubly linked list
- `O(1)` get and put
- eviction policy

## Milestones

1. support `get(key)`
2. support `put(key, value)`
3. move recently used items to the front
4. evict least recently used item
5. add tests for overwrite and capacity edge cases
