# Ride Matching System

## Why Build It

This project makes heaps, maps, graphs, and spatial reasoning feel useful together.

## Concepts

- priority selection
- proximity search
- matching logic
- dynamic updates

## Milestones

1. model riders and drivers
2. find nearest available driver
3. handle driver status updates
4. support simple pricing or ETA logic
5. discuss scaling, hotspots, and fairness
