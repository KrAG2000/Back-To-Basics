# Engineering Core

`engineering-core/` is a standalone course that turns interview prep into an engineering campaign.

This folder is intentionally independent from `cpp-playground/`.

The goal is to build:

- strong interview-grade fundamentals
- backend and systems reasoning
- production mental models
- project depth that compounds into architecture maturity

## How This Course Works

The course is split into eight worlds.

Each world has:

- lessons to build the mental model
- drills to force recall and speed
- a build quest to connect ideas
- a boss project to make the topic real
- a review gate to confirm understanding

## 12-Week Hyper-Focused Track

1. Weeks 1-2: Machine memory and data logic
2. Weeks 3-4: Requests, networking, storage, and databases
3. Weeks 5-6: Processes and concurrency
4. Weeks 7-8: Service construction
5. Weeks 9-10: Distributed systems
6. Weeks 11-12: Architecture arena

## Automation

This folder also includes a local-first progress system:

- repo-wide file activity tracking
- git history summaries
- world-level progress inference
- a static dashboard with daily views
