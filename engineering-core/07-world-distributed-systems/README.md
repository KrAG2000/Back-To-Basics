# World 7: Distributed Systems

This world studies what breaks when one machine is no longer enough.

## Core Questions

- How do you scale reads and writes?
- When do you choose consistency over availability, or the reverse?
- How do caches, queues, replication, and sharding interact?

## Output

- more credible large-scale design answers
- better failure-mode reasoning
- clearer language around distributed tradeoffs
