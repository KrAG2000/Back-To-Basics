# Dashboard

The dashboard is a local static view of your repo activity.

Open [index.html](/home/life-workstation/Personal_Projects/Back-To-Basics/engineering-core/90-dashboard/index.html) after generating data.

## Quick Start

1. `python3 engineering-core/80-automation/generate-progress.py`
2. Open `engineering-core/90-dashboard/index.html`
3. Optional: `python3 engineering-core/80-automation/watch-progress.py`
4. Optional: `bash engineering-core/80-automation/install-git-hooks.sh`
