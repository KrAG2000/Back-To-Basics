# World 5: Processes and Concurrency

This world explains what happens when more than one unit of work wants progress at the same time.

## Core Questions

- When do you want processes vs threads?
- Why do locks solve one class of problems while creating another?
- How do queues, retries, and backpressure change production behavior?

## Output

- better concurrency reasoning
- fewer hand-wavy answers around scheduling and synchronization
- more realistic intuition for throughput and contention
