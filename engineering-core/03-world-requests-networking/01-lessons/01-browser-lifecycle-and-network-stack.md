# Browser Lifecycle and Network Stack

Typing a URL kicks off a pipeline, not a single action.

## Sequence

1. cache checks
2. DNS resolution
3. IP routing
4. TCP connection setup
5. TLS handshake
6. HTTP request and response
7. browser parsing and rendering

## Why This Matters

This is one of the highest-ROI interview topics because it connects:

- networking
- security
- backend services
- performance
- debugging
