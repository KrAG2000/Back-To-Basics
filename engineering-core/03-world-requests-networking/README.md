# World 3: Requests and Networking

This world follows data across the network and through service boundaries.

## Core Questions

- How does a browser or client reach a service?
- Why do latency, retries, and protocol choices change behavior?
- How do sockets, HTTP, and APIs relate without feeling like separate topics?

## Output

- stronger explanation of request lifecycles
- better understanding of network cost and failure
- clearer backend API reasoning

## World Path

Start with the browser lifecycle, then move down and back up the stack.
