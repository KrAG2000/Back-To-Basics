# Boss Project Ladder

Each world culminates in one project that forces the theory to become muscle memory.

## World 1

- `memory-cache-explorer`
- Build a small visual or console tool that demonstrates stack vs heap, cache locality, and layout effects.

## World 2

- `dsa-toolkit`
- Build reusable implementations and problem packs for arrays, trees, heaps, graphs, and search patterns.

## World 3

- `socket-http-service`
- Build a socket-based service and inspect the HTTP request lifecycle end to end.

## World 4

- `persistent-kv-store`
- Build a small key-value store with append logging, recovery, and indexing ideas.

## World 5

- `job-queue-scheduler`
- Build a queue with worker behavior, retries, and visibility into contention.

## World 6

- `production-api-service`
- Build a backend service with auth, rate limiting, background jobs, and observability hooks.

## World 7

- `distributed-systems-slices`
- Build or document scale-oriented slices such as caching, pub-sub, search, or replication experiments.

## World 8

- `architecture-capstone`
- Produce an architecture dossier for one large system with estimates, tradeoffs, risks, and failure handling.
