# Control Tower

This is the command center for the course.

Use this folder to understand:

- the world order
- the 12-week roadmap
- the boss project ladder
- the metadata that powers the dashboard

## Files

- `roadmap-12-weeks.md`: the short, aggressive prep schedule
- `world-map.yaml`: world definitions, prerequisites, and XP targets
- `lesson-index.yaml`: the lesson catalog for the full course
- `tracker-rules.yaml`: repo-wide progress rules and ignore patterns
- `project-ladder.md`: the full boss-project progression

## Operating Rule

You do not need to finish one world perfectly before touching the next one.

You do need to respect the order enough that deeper topics rest on stable foundations.
