# 12-Week Hyper-Focused Roadmap

This plan is designed for an aggressive backend-and-systems interview ramp.

## Weeks 1-2

- World 1: machine memory
- World 2: data logic
- Outcome: solve foundational questions with clean mental models

## Weeks 3-4

- World 3: requests and networking
- World 4: storage and databases
- Outcome: explain how modern applications move data end to end

## Weeks 5-6

- World 5: processes and concurrency
- Outcome: reason about contention, scheduling, coordination, and failure

## Weeks 7-8

- World 6: service construction
- Outcome: build backend services with clearer boundaries and tradeoffs

## Weeks 9-10

- World 7: distributed systems
- Outcome: talk about scaling, consistency, reliability, and cost

## Weeks 11-12

- World 8: architecture arena
- Outcome: handle senior-style design rounds and tradeoff conversations

## Weekly Rhythm

1. Read one lesson block.
2. Create drill notes or solutions.
3. Build the quest artifact.
4. Push the boss project forward.
5. Review with the gate prompts.
6. Let the dashboard track your momentum automatically.
