# Bits, Binary, and CPU Thinking

The machine only knows state transitions over bits.

## What to Know

- binary, hex, and two's complement
- how integers and characters are represented
- what a CPU actually does at a high level: fetch, decode, execute
- why instructions, registers, and memory are separate concerns

## Interview Value

This lesson makes you better at:

- bitwise reasoning
- overflow intuition
- cost modeling instead of memorizing complexity alone

`Why is array indexing fast, and what does the CPU need to do to load arr[i]?`
