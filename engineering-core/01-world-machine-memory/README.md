# World 1: Machine Memory

This world builds the mental model underneath every later system topic.

## Core Questions

- How does data actually live in memory?
- Why do stack, heap, cache, and layout decisions change performance?
- Why do bugs like leaks, corruption, and undefined behavior happen?

## Output

- explain memory layout clearly in interviews
- reason about complexity and locality together
- debug with a lower-level model instead of guesswork
