# Core DSA as Decision Tools

Treat each structure as an answer to an access pattern.

## What to Know

- arrays for indexed, cache-friendly access
- hash maps for direct lookup
- heaps for top-k and dynamic priorities
- trees for ordered queries
- graphs when relationships drive the problem

## Interview Value

The strongest candidates do not say:

`I saw this on LeetCode.`

They say:

`This structure fits the operations mix, update profile, and query shape.`
