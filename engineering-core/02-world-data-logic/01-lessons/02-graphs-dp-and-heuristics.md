# Graphs, DP, and Interview Heuristics

This lesson is about problem shape recognition.

## Watch For

- graph problems disguised as strings, matrices, or state transitions
- DP problems disguised as repeated decision trees
- greedy solutions that only work after proving the invariant

## Heuristics

Ask in order:

1. Is there repeated work?
2. Is there a shortest-path or reachability view?
3. Is order important?
4. Can state be compressed?
